# aulaconecta-frontend-equipo-05
Repositorio del front-end del proyecto AulaConecta
1.PROBLEMA
Actualmente los archivos del proyecto se comparten mediante carpetas y aplicaciones de mensajeria, generando multiples versiones, perdida de cambios y dificultades para trabajar en equipo.
2.OBJETIVO
Crear un repositorio organizado que permita desarrollar el fron-end de AulaConecta utilizando buenas practicas de conrol de versiones y colaboracion mediante Git y GitHub.
3.ALCANCE INICIAL
-Pagina de inicio.
-Pagina de cursos.
-Formulario de registro.
-Panel de administracion de contenidos.
-Pagina de contacto.
