Expliación De Los Comandos:

Git Commit: Guarda un registro permanente de los cambios realizados en el proyecto para conservar su historial.
Git Branch: Crear una nueva rama para desarrollar cambios sin afectar la rama principal.
Git Checkout: Permite cambiar entre ramas para trabajar en una version especifica del proyecto. 
Git Merge: Une los cambios de una rama con otra intregrando el trabajo realizado.
